### Backend for the Task Manager App

A backend project developed with **Spring Boot** that exposes a REST API for managing **tasks** and **category**.

It includes:
- ✅ CRUD functionality
- 🧠 Validation with `@Valid`
- ⚙️ Custom exception handling
- 🧪 Unit testing with **JUnit 5** and **Mockito**

Currently, it uses an **in-memory H2 database** for simplicity of development, but it will be replaced with **PostgreSQL** in a future version.

---

### 🛠️ Tech Stack
- **Language:** Java 21
- **Framework:** Spring Boot 3
- **Database:** H2 (in-memory) → PostgreSQL (coming soon)
- **Build Tool:** Maven
- **Testing:** JUnit 5, Mockito
- **Other:** Spring Data JPA, Lombok, Jakarta Validation
